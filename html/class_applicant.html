Подробное описание

Класс, описывающий абитуриента.

Поля: ФИО, факультет, специальность, сумма баллов. Сравнение выполняется по правилам варианта 16:

  • сначала сумма баллов по убыванию,
  • затем ФИО по возрастанию,
  • затем факультет по возрастанию,
  • затем специальность по возрастанию.
